# Dungeon Ascendant

GitHub Pages üzerinde doğrudan çalışabilen, harici oyun motoru/asset gerektirmeyen özgün bir 3D raycasting roguelike FPS prototipi.

## Oynanış
- `WASD`: hareket
- Mouse: bakış / nişan
- Sol tık: ateş
- `Shift`: dash / hızlı hareket
- Düşmanları yenerek XP kazan, level atla ve 3 yükseltmeden birini seç.
- Tüm düşmanlar bitince yeni ve daha zor bir floor oluşur.
- Can ve enerji pickup'ları build'i destekler.

## Teknik
- Saf HTML + CSS + JavaScript + Canvas 2D raycasting.
- Prosedürel zindan üretimi.
- 3 düşman tipi, ölçeklenen zorluk, XP/level sistemi ve upgrade seçimleri.
- Harici 3D model veya telifli oyun asset'i kullanılmaz.

## Yayınlama
GitHub Pages'te repository kökünü yayınlamak yeterlidir; `index.html` giriş noktasıdır.
